# Asset sources

- `profile-header-dark.svg`, `profile-header-light.svg`: original vector banner authored for this profile, 2026-10-05, generated by `make_header.py`. A control-room single-line diagram in night and day palettes; equipment stays grayscale and colour marks events only (ISA-101 style). System fonts only: Bahnschrift on Windows, DIN Alternate on macOS, condensed sans fallbacks elsewhere. No external fonts, images or scripts. The event animation respects `prefers-reduced-motion` and falls back to a static CVE line. Edit the labels or events in `make_header.py` and run `python assets/make_header.py` to regenerate both files.
- `dots-on-paper.jpg`: existing public Dots on Paper artwork, copied from https://raw.githubusercontent.com/heinrihs-s/dots-on-paper/main/brand/header-paper-v2.png on 2026-10-04 and re-encoded as a 1600 × 800 JPEG on 2026-10-05 (1.9 MB → 155 KB).
- `cloakspan-demo.gif`: existing public Cloakspan synthetic terminal demo, copied from https://raw.githubusercontent.com/quiethours-eu/cloakspan/main/docs/assets/cloakspan-demo.gif on 2026-10-04.

The profile uses GitHub-native links and expandable `details` sections. The banner switches with the viewer's GitHub theme through a `<picture>` element. The companion interaction lives at https://heinrihs.org/dotsonpaper/#demo; no JavaScript runs inside the README.
